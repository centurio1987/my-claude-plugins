# 문체 설정 체계 — 조사와 설계 결정

문체 설정(어휘 목록·정성 지시)의 분류 체계는 **조사를 먼저 하고** 그 결과로 짰다.
이 문서는 조사 결론과 그것이 어떤 설계 결정으로 이어졌는지를 한 곳에 모은다.
원 조사 노트는 `research/` 에 그대로 두었다.

| 노트 | 다루는 것 |
| --- | --- |
| `research/lexicon-notes.md` | 정량 갈래 — 한국어 품사·어미 체계, 메타담화 기능, 번역투·문체 지침의 합의 정도, LLM 한국어 표지 |
| `research/qualitative-notes.md` | 정성 갈래 — 문체론 체크리스트, 사용역, 입장·관여, 명료성 원칙, 한국어 문체론 |

## 검증 수준 — 먼저 밝혀 둔다

조사는 2026-09-24 에 했다. 원문 페이지 열람(WebFetch)이 네트워크 정책에 막혀 **검색 결과의 초록·스니펫으로만**
확인했다. 노트의 모든 주장에 확인 수준이 붙어 있다.

| 표지 | 뜻 |
| --- | --- |
| `[확인]` · 검증 | 초록·스니펫에서 내용을 확인 |
| `[부분]` · `[부분검증]` | 서지나 요지만 확인 |
| `[미확인]` · `[미검증]` | 일반 지식이거나 이 설계의 제안 |

**모든 수치 임계값(밀도·겹침 기준, 가중치 대역의 허용량)은 설계 초기값이다.** 코퍼스로 검증한 값이 아니라서
편집기에서 층마다 조정할 수 있게 열어 두었다. 이 저장소의 한국어 문서 17편에서 초기값이 적발을 내지 않는지,
일부러 과장해 쓴 표본에서는 적발을 내는지만 확인했다 — 보정이 아니라 점검이다.

## 1. 정량 갈래 — 어휘 목록

### 1.1 두 축으로 가른다

어휘 항목 하나에는 **"무엇인가"** 와 **"무슨 일을 하는가"** 가 따로 있다. 둘을 한 트리에 섞으면
'헤지'가 부사에도 어미에도 구에도 있어서 트리가 깨진다.

| 축 | 내용 | 항목당 | 근거 |
| --- | --- | --- | --- |
| **형식**(분류 트리) | 5언 9품사 → 하위 부류, 접사, 어미(종결·연결·전성·선어말), 구 단위 표현 | 노드 하나 | 학교문법(1985 통일), 어미 체계, 부사 하위 분류 |
| **기능**(태그) | Hyland(2005) 메타담화 10갈래 + 한국어 문체 태그 | 여러 개 | Hyland & Tse(2004), 한국어 4장르 메타담화 연구, 번역투 연구 |

어종(고유어·한자어·외래어)은 **노드가 아니라 속성**이다. 이번 판에서는 대체어(`alternatives`)로만 반영했다 —
한자어 비율 단독이 난도를 정한다는 근거를 찾지 못했다(`lexicon-notes.md` §6.2).

### 1.2 세는 자리는 형식이 정한다

어디서 세야 의미가 있는지는 주로 **형식**이 정하고, 왜 나쁜지는 **기능**이 정한다(`lexicon-notes.md` §2).
그래서 점검 방식을 분류 노드에 두고 항목이 덮을 수 있게 했다.

| 점검 | 구현 | 적용 분류 | 근거 |
| --- | --- | --- | --- |
| 어디서나 | `mode: count` | 기본값 | — |
| 문장 머리 | `mode: sentence-initial` | 접속부사, 감탄사, 서수·요약 표지 | 접속부사는 문두에 온다 |
| 문장 끝 + 점유율 | `mode: sentence-final` | 종결어미, 명사화 문말 구성 | 종결어미가 문장 유형·높임 등급을 정한다 |
| 한 문장 안 겹침 | `check.stack` | 양태부사, 정도부사, 복합조사, 관형격 '의', '-적', 연결어미 | 신문 헤지 연구 — 헤지는 중첩돼 쓰인다 |
| 분류 밀도 | `check.density_per_1000` | 의존명사, 추상 명사, 정도부사, 기능동사, '-들', '-적' | 적당히는 정상인 항목 |

### 1.3 기본 가중치 — 합의가 확인된 것만 음수

가중치는 사용자가 정한다. 플러그인 기본값은 **문헌 합의가 확인된 것만** 음수로 두고 나머지는 0(보통)이다.
목록은 주되 판단을 강요하지 않는다.

| 기본값 | 항목 | 근거 |
| --- | --- | --- |
| **-3 금지** | 이중 피동(되어지다·보여지다), '에의' | 국립국어원 온라인가나다, 이오덕, 최유숙(2023): 가장 많이 논의된 번역투 |
| **-1 절제** | '에 대해/대한'·'을 통해'·'에 의해'·'에 기반하여'·'의 관점에서', '-적', '-들', '그녀', '-었었-', 조사+의 | 이오덕, 이수열, 김정선, 김정우(2012) |
| **0 보통** | '-ㄹ 수 있다', '너무', '로부터'·'을 위한' | '-ㄹ 수 있다'는 학술 텍스트의 정상 헤지(이윤진 2014), '너무'는 2015년 긍정 문맥 허용, 나머지는 1차 인용 미확인 |

최유숙(2023)은 번역투 수정안 가운데 **부적절한 것도 있다**고 재검토했다. 그래서 금지는 두 항목으로 좁혔다.

기존 L0 스캐너 어휘(W·H·D 코드)는 **원래 판정을 그대로** 옮겼다 — S1 은 -3, S2 는 -2, S3 는 -1.
옮기기 전후로 같은 입력에 같은 적발이 나오는지 대조했다.

### 1.4 LLM 표지 어휘는 조심해서 쓴다

한국어 LLM 문체 변화에 관한 가장 큰 연구(Lee 2026, KCI 초록 398,296편)는 번역투가 아니라
**한자어 학술 레지스터로의 이동**(시사하다·확인되다·구조적 상승, 알아보다·살펴보다 하락)을 보고했다.
다만 학술 초록 한정이고 동료심사 전이다. 그래서 `llm-register` 태그만 달고 가중치는 0 으로 두었다.
Kobak 외(2025)를 따라 내용어가 아닌 **문체어만** 올렸다.

## 2. 정성 갈래 — 지시 목록

### 2.1 아홉 범주, 마흔한 말단 — 축 하나씩

정성 지시는 사용자가 쓴다. 분류 체계는 지시가 **어느 요소를 겨누는지** 정하고, 채점자가 읽으며 물을
**판정 질문**을 준다. 모든 범주는 voice 의 L1 축 넷 가운데 **정확히 하나**에 묶였다 — 갈래 소유권을 지키기 위해서다.

| 축 | 범주 | 이론 |
| --- | --- | --- |
| `register` | `tenor` 격식·관계 (5) · `stance` 입장·평가 (5) | Halliday tenor/mode, Joos 5단계, 상대높임법 / Hyland stance, Martin & White Appraisal |
| `rhythm` | `cadence` 문장 호흡 (5) · `pacing` 전개 완급 (4) | 이태준 『문장강화』, Provost, Quirk end-focus, Williams / Biber, Clark |
| `device` | `figure` 수사 문채 (3) · `engage` 독자 관여 (5) · `illus` 예시·사례 (3) · `frame` 도입·마무리 (2) | Silva Rhetoricae, 수사법 3분류 / Hyland engagement / Hayakawa / hook 유형론 |
| `lexicon` | `diction` 어휘 선택 (9) | Leech & Short, Strunk & White, Williams, 국립국어원 쉬운 공공언어 |

### 2.2 이태준의 세 대립은 세 축으로 갈린다

| 대립 | 무엇이 다른가 | 말단 | 축 |
| --- | --- | --- | --- |
| 간결체 ↔ 만연체 | 구절의 길고 짧음 | `cadence.length` | rhythm |
| 강건체 ↔ 우유체 | 표현의 세기 — Appraisal 의 Graduation/Force 와 대응 | `stance.force` | register |
| 건조체 ↔ 화려체 | 수식·미사여구의 양 — 단어 단위 선택 | `diction.ornament` | lexicon |

### 2.3 다른 층의 것은 받지 않는다

| 현상 | 소유 |
| --- | --- |
| 섹션 존재·순서, 두괄식 배치 | `structure` (L2) |
| 사실·수치·인용의 정확성 | `evidence` (L0) |
| 번역투, 이중 피동, 비문, 호응 오류 | `grammar` (L0) |
| 용어 첫 정의, 점진적 공개, 구정보→신정보, 주제 연쇄 | `comprehension` (L0) |
| 셀 수 있는 것(평균 문장 길이, 종결 비율, 금지어 수) | 정량 갈래 |

겹칠 때의 판정 규칙: **비문·부자연이면 grammar, 자연스럽지만 밋밋하면 lexicon.** 정성 말단은
"그 수치가 이 글의 목적·독자·장르에 맞는가"라는, 읽어야만 판단할 수 있는 적합성만 다룬다.

### 2.4 게이트는 읽고만 판정한다

정성 지시를 게이트에 붙이면 채점자는 **스크립트·정규식·카운터를 만들지 않고** 본문을 읽어 판정한다.
이 규칙은 분류 체계 파일(`qualitative.json` 의 `judging.rules`)에 있고, 해석 결과와 게이트 스킬이 같은 문장을 본다.

- 지시마다 본문 인용(최대 3곳)을 근거로 충족/미흡을 낸다. 인용이 안 나오면 미흡이다.
- 스펙트럼형 요소는 "지시가 정한 위치 대비 실제 위치"를 한 줄로 적는다.
- 먼저 무엇을·누구에게·어떤 매체로 쓰는 글인지 확인한다(Halliday field·tenor·mode).
- 일관성은 말단이 아니라 **공통 질문**이다 — 글 전체에서 흔들리지 않는가, 흔들림은 의도적인가.

## 3. 조사가 설계를 바꾼 자리

| 조사 전 가정 | 조사 결과 | 바뀐 설계 |
| --- | --- | --- |
| 번역투는 대부분 금지 | 수정안 자체가 부적절한 경우가 있다(최유숙 2023) | 금지는 이중 피동·'에의' 둘로 좁히고 나머지는 -1 |
| '-ㄹ 수 있다'는 헤지 남발 신호 | 학술 텍스트의 정상 고빈도 헤지(이윤진 2014) | 가중치 0, 문말 점유율로만 보고 |
| 헤지는 개수로 센다 | 헤지는 한 문장 안에 **중첩**되어 쓰인다(신문 헤지 연구) | 분류 점검에 `stack` 을 두었다 |
| 한자어 비율을 지표로 | 단독 난도 결정 근거 없음 | 지표에서 뺐다 — 대체어로만 반영 |
| AI 표지는 번역투 | 한자어 학술 레지스터로 이동(Lee 2026) | `llm-register` 태그, 가중치 0 |
| 정성 분류는 축 넷에 바로 | 이태준 세 대립이 서로 다른 축에 속한다 | 범주를 축별로 나누고 대립마다 말단 하나 |
| '톤' 지시는 한 요소 | 세기(강↔약)와 무게(진지↔경쾌)가 섞인다 | `stance.force` 와 `tenor.key` 를 나누고 경계 설명에 적었다 |

## 4. 남은 것

- 한국어 블로그·기술문에서 LLM 말투 어휘의 코퍼스 증거 — 찾지 못했다. 사용자 코퍼스로 검증해야 한다.
- 국립국어원 공공언어 지침의 구체적 번역투 교정 목록 — 원문을 열지 못했다.
- 표층 문자열 매칭의 중의성('수'·'의'·'적'·'것 같다') — 형태소 분석기 없이 정규식과 예외 문맥으로 줄였을 뿐
  없애지 못했다. 이 키트는 표준 라이브러리만 쓴다는 원칙을 지켰다.
- 밀도·겹침 기준값 — 설계 초기값이다. 쓰면서 조정한 값을 전역 설정에 쌓는 것이 다음 단계다.
