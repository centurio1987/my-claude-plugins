# authoring-style (문체 설정 편집)

voice 의 **어떻게 말하는가**를 두 갈래로 나눠 관리한다. 분류 체계는 조사를 거쳐 짰다(`assets/STYLE_RESEARCH.md`).

| 갈래 | 무엇 | 판정 |
| --- | --- | --- |
| **정량 — 어휘 목록** | 품사·어미·구 단위로 분류한 어휘 항목. 항목마다 **가중치**(-3 금지 ~ 0 보통 ~ +3 표지)와 **필터**(채택/제외) | `scan_lexicon.py` 가 센다 |
| **정성 — 지시 목록** | 문체 요소 분류(9범주 41말단 + 사용자가 만든 하위 범주)에 묶인 사용자 지시문 | 게이트 채점자가 **읽고만** 판정한다 |

**전역 설정이 있고 voice 는 그것을 계승·확장한다.** 플러그인 기본값 → 전역 → voice 순으로 겹치며,
각 층은 바꾼 것(차분)만 저장한다. 스키마는 `assets/STYLE_SCHEMA.md`.

## 1. 편집기를 연다

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/authoring.py style serve --open      # http://127.0.0.1:8765/
```

- 서버는 백그라운드로 띄우고, 사용자에게 주소를 알려 준다. 끝나면 종료한다.
- 로컬(127.0.0.1)에만 붙는다. 원격 세션이라 브라우저가 없으면 아래 CLI 로 편집한다.

편집기에서 할 수 있는 것:

- **편집 대상** — 전역 또는 voice 하나. voice 를 고르면 전역에서 계승한 값과 이 voice 가 바꾼 값이 배지로 갈린다.
- **어휘 목록** — 분류 트리로 좁히고, 기능 태그(헤지·번역투·빈 상찬…)·가중치·출처로 거른다. 가중치 7단 버튼,
  채택 스위치, 분류 단위 스위치, 분류 점검 기준값(밀도·겹침) 조정, 항목 추가.
- **정성 지시** — 분류를 누르면 정의·스펙트럼·판정 질문·지시 예시가 보이고, 예시를 누르면 지시로 추가된다.
  상위 옆 ‘+ 범주’로 그 밑에 범주를 직접 만들고(이름·정의·판정 질문), 지시마다 범주를 고른다.
  지시마다 채택·게이트(MUST/SHOULD)·예문.
- **모델 지시문 미리보기** — `resolve` 가 L1 절에 싣는 부분을 저장 전에 본다.
- **시험 스캔** — 글을 붙여 넣으면 저장 전 설정으로 가중치 어휘 스캔과 L0 문체 등급을 함께 낸다.

**저장은 검증을 통과해야만 된다.** hard floor 항목을 올리거나, 사유 없이 L0 항목을 면제하면 거부되고 이유가 보인다.

## 2. 편집기 없이 — 대화로 편집할 때

사용자가 "이 단어 쓰지 않게 해줘"처럼 말하면 편집기를 띄우지 않고 직접 고쳐도 된다.

1. 어느 층인지 정한다 — 모든 글에 적용이면 전역, 한 퍼소나면 그 voice. **모호하면 묻는다.**
2. 현재 유효값을 본다.
   ```bash
   python3 ${CLAUDE_PLUGIN_ROOT}/scripts/authoring.py style show [--voice <id>] [--json]
   ```
3. 그 층의 `style.json` 에 **차분만** 쓴다(`overrides` · `categories` · `add`). 기본 카탈로그 파일은 고치지 않는다.
   카탈로그에 없는 말이면 알맞은 형식 분류를 골라 `add` 로 넣는다 — 분류는 `STYLE_SCHEMA.md` 와
   `lexicon.json` 의 `categories` 에서 고른다.
4. 검증한다. 실패하면 고치고 다시 한다.
   ```bash
   python3 ${CLAUDE_PLUGIN_ROOT}/scripts/authoring.py style validate
   ```

정성 지시를 받을 때:

- 지시가 **어느 말단**을 겨누는지 고른다. 맞는 말단이 없으면 가장 가까운 상위 밑에 사용자 범주를 만든다(`STYLE_SCHEMA.md`). '톤'처럼 모호하면 세기(`stance.force`)인지 무게(`tenor.key`)인지 되묻는다.
- 다른 층의 것이면 받지 않고 그 층으로 보낸다 — 섹션 순서(spec), 사실 정확성·번역투·용어 정의(L0).
- 셀 수 있는 규칙이면("'매우' 쓰지 마") 지시가 아니라 **어휘 목록의 가중치**로 옮기자고 제안한다.

## 3. 집필·게이트와의 연결

- `authoring.py resolve` 가 L1 절 뒤에 **유효 문체 설정**을 싣는다. 가중치 0 항목과 L0 스캐너가 이미 세는
  기본 항목은 싣지 않는다(바뀐 것만).
- `authoring-gate` 는 `scan_lexicon.py --voice <id>` 로 어휘 가중치를(V5), 게이트에 붙은 지시를 읽기로(V6) 판정한다.
- L0 기계 리듬 어휘(W·H·D 코드)를 voice 가 끄거나 양수로 올리면 **항목 단위 면제**다 — `scan_ai_style.py --voice`
  가 그 항목을 빼고 잰다. 사유가 필수다.
- `authoring.py lock` 이 기본 카탈로그와 전역 설정의 해시를 고정한다. 설정을 바꿨으면 `lock --update` 하고 이유를 커밋에 남긴다.

## 참조

- `assets/STYLE_RESEARCH.md` — 조사 결론과 설계 결정, 검증 수준
- `assets/research/lexicon-notes.md` · `assets/research/qualitative-notes.md` — 원 조사 노트

## 주의

- **전역에 한 사람의 문체를 넣지 않는다.** 전역은 모든 voice 가 계승한다 — 이 키트가 고치려던 사고가 그것이다.
  특정 퍼소나의 색은 그 voice 층에 둔다.
- 기본 카탈로그의 기준값(밀도·겹침·허용량)은 **설계 초기값**이다. 쓰면서 조정한다.
- 양수 가중치는 "억지로 넣으라"가 아니다. 자리가 왔을 때 그 말을 고르라는 뜻이다.
