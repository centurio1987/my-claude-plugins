# 명세 인터뷰 — 다섯 입력을 받는 법

> **역추출을 먼저 제안한다.** 백지에서 묻는 것보다 이미 쓴 글에서 뽑는 쪽이 정확하고 빠르다.
> 아래 질문은 **추출로 못 채운 칸에만** 쓴다. 채워진 칸은 "이렇게 이해했는데 맞나요"로 확인만 한다.

## 0. 역추출 제안

> "이미 쓰신 글이 있으면 거기서 명세를 뽑아 드릴까요? 완성된 글 1~3편이나
> 템플릿·캔버스 파일, 기존 체크리스트 중 아무거나 주시면 됩니다."

받을 수 있는 것과 그것으로 채워지는 칸:

| 준 것 | 채워지는 칸 |
| --- | --- |
| 완성된 글 1~3편 | ① 항목 · ② 작성 방법(관찰된 패턴) |
| 템플릿·캔버스 | ① 항목(골격이 이미 고정) · ⑤ 템플릿 |
| 기존 체크리스트 | ③ 범위 원칙 |
| 기존 글의 저자 표기 | ④ 퍼소나 후보 |

**추출한 것은 추정이다.** 확정 전에 반드시 보여 주고, 종료 보고에 "추출로 채운 것 / 직접 답한 것"을
구분해 남긴다.

## ① 항목 — 무엇으로 이루어지는가

> "이 글은 어떤 부분들로 이루어지나요? 순서대로 알려 주세요."

이어서 각 항목마다:

- **반드시 있어야 하나요, 있을 때만인가요?** — 조건부면 **어떤 조건일 때** 쓰는지.
- **제목 문구가 고정인가요, 내용에 맞춰 지어도 되나요?**
  (고정이면 `heading_fixed: true` — 나중에 채점이 이 문구로 항목을 찾는다)
- **여러 번 반복되나요?** (경력 항목, 최적화 라운드처럼)

> **조건부 항목은 생략 규칙까지 정한다.** 해당 없을 때 절을 지우는지, "해당 없음"을 남기는지.
> 이 하나가 글의 품질을 가른다 — 독자용 문서에 집필 메타가 남으면 그 자체로 감점이다.

## ② 항목별 작성 방법 — 각 자리에서 무엇을 하는가

> "`<항목>` 은 무엇을 하는 자리인가요? 잘 쓴 예와 못 쓴 예를 하나씩 들어 주시면 가장 좋습니다."

받아야 하는 것:

- **직무** — 이 절이 독자에게 무엇을 해 주는가.
- **분량 감각** — 3문장 이하인지, 한 문단인지, 제한이 없는지.
- **필수 요소** — 반드시 들어가야 하는 것(코드 블록·수치·도식·예시).
- **하지 말 것** — 이 자리에서 흔히 나는 실수.

추상적 형용사("자세하게", "간결하게")만 받고 넘어가지 않는다. **예문 하나가 형용사 열 개보다 낫다.**

## ③ 해당 글 범위의 원칙 — 이 글 종류에서만 지킬 것

> "이 글에서만 지켜야 하는 규칙이 있나요? 다른 글에는 해당 없지만 이 글에는 꼭 필요한 것요."

받은 것마다 셋을 정한다:

- **강도** — 없으면 아예 실패인가(MUST) / 아쉬운 정도인가(SHOULD) / 해당할 때만인가(IF-APPLICABLE).
- **축** — 구성에 관한 것인가(`structure`), 이 글만의 원칙인가(`scope-principle`),
  사실 정확성인가(`evidence`).
- **판정 가능성** — 채점자가 본문을 보고 충족/미흡을 가를 수 있게 쓰였는가.

> 말투·호흡·독자 장치 얘기가 나오면 **여기가 아니라 퍼소나(④)** 다. 그렇게 안내한다.

## ④ 적용 퍼소나 — 누구 목소리로 쓰는가

`authoring.py list voices` 결과를 보여 주고 고르게 한다.

> "이 글은 누구 목소리로 쓰나요?"

- 없으면 → **`authoring-voice` 등록으로 분기**한다. 여기서 문체를 캐묻지 않는다.
- 여러 화자가 나오는 글이면 → **화자별로** 어느 voice 인지 받는다(`voice_map`).
- 하나로 정해지면 `allowed` 를 그 하나로 좁힌다 — 나중에 실수로 다른 목소리가 붙는 것을 막는다.

## ⑤ 템플릿 — 이미 있는가, 만들 것인가

> "쓰던 템플릿 파일이 있나요? 없으면 원하는 형태를 말씀해 주시면 만들어 드립니다."

**(a) 있다** → 경로를 받아 수입한다. 슬롯을 뽑아 항목과 대응시키고, 대응이 안 되는 슬롯은 물어본다.
템플릿 파일은 **프로젝트에 그대로 둔다.**

**(b) 없다** → 요구사항을 받는다:

- 어떤 형식인가(마크다운·HTML·슬라이드·문서).
- 지면 제약이 있는가(1페이지, N슬라이드).
- 채워 넣을 자리가 어디인가 — ①에서 받은 항목과 대응시킨다.
- 고정 문구가 있는가.

만든 뒤 **보여 주고 확인받은 다음** 저장한다.

## 마무리 — 확인 후 저장

저장 전에 요약을 보여 준다:

```
항목      15개 (필수 13 · 조건부 2)
작성 방법  항목마다 있음 / 빠진 것: (없음)
범위 원칙  24개 (MUST 14 · SHOULD 3 · IF-APPLICABLE 7)
퍼소나    ppangtolab-teacher (다른 voice 로는 해석 불가)
템플릿    수입 — algo-guide-canvas
```

빠진 칸이 있으면 저장하지 말고 마저 받는다. **비워 두고 나중에 채우겠다는 것은 대개 안 채워진다.**
