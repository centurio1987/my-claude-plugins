# KAN-002-0J9YP1 — authoring-kit 문체 설정 앱 — 정성 지시 범주를 사용자가 직접 만들고 항목에서 고른다

## 전략
**정정(2026-09-27).** 첫 계획은 요청을 「사용자가 새 범주를 만든다」로 잘못 읽었다. S1~S4 는 그 기능이었고 `051f355` 로 되돌렸다. 유저가 확인한 의도는 **분류마다 고를 수 있는 선택지 목록(여러 개 체크)** 이고, 직접 쓰는 지시는 그대로 둔다.

- **선택지의 출처** — 플러그인 분류(`qualitative.json`) 하위 41개에 이미 있는 두 재료를 선택지로 쓴다. 스펙트럼 값(`poles`, 40개 분류)은 「이 분류를 어느 쪽으로 맞출 것인가」라서 **한 분류에 하나만** 켜진다. 지시 예시(`templates`, 41개 분류 각 2개)는 서로 겹치지 않아 여러 개 켤 수 있다. 선택지마다 고정 id(`s1…`·`t1…`)를 카탈로그에 박아, 문구를 다듬어도 사용자 설정이 끊기지 않게 한다.
- **저장** — 층 파일의 `directives.choices` 에 `{분류 id: [선택지 id…]}` 로 적는다. voice 가 어떤 분류를 적으면 그 분류는 전역 선택을 **통째로 대신**하고, 빈 목록은 「이 voice 에서는 아무것도 고르지 않음」이다. 적지 않은 분류는 전역을 물려받는다.
- **집필 반영** — 고른 선택지는 유효값에서 지시 한 줄로 바뀌어, 직접 쓴 지시와 같은 자리(L1 절의 정성 지시)에 실린다. 지시 id 는 `<분류>#<선택지>` 다.
- **제약** — 기본값은 아무것도 고르지 않은 상태라 기존 설정의 결과가 바뀌지 않는다. 표준 라이브러리만 쓰고, 잘못된 선택은 저장 전에 거부한다.
- **버린 대안** — 선택지를 사용자가 직접 만드는 목록(유저가 고르지 않음) · 스펙트럼도 여러 개 허용(「격식」과 「친밀」을 동시에 지시하게 된다) · 선택지를 게이트에 붙이는 기능(이번 요구에 없다. 필요하면 직접 쓴 지시로 옮겨 게이트를 켠다).
