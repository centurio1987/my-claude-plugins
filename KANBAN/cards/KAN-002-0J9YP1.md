# KAN-002-0J9YP1 — authoring-kit 문체 설정 앱 — 정성 지시 범주를 사용자가 직접 만들고 항목에서 고른다

## 전략
**사용자 범주는 층 파일의 차분으로 둔다.** 플러그인 분류 체계(`qualitative.json`)는 읽기 전용으로 두고, 층 파일(`global/style.json` · `voices/<id>/style.json`)의 `directives.categories` 에 사용자가 만든 하위 범주를 적는다. 유효값을 계산할 때 기본 분류 → 전역 → voice 순서로 겹친다. 지시 항목이 계승되는 방식과 같다.

- **위치** — 기존 상위 9개 밑의 하위로만 만든다(유저 결정, 2026-09-27). 담당 축은 상위에서 물려받고 따로 적지 않는다. 그래서 L1 갈래 소유권 검사와 게이트·미리보기가 지금 경로 그대로 돈다.
- **범주 필드** — `id`(`<상위>.<이름>`) · `parent` · `label` · `definition`(선택) · `questions`(선택, 게이트 판정 질문으로 실린다).
- **삭제 안전** — 지시가 쓰고 있는 범주는 지울 수 없다. 전역 범주를 voice 지시가 쓰고 있으면 전역 저장이 거부된다.
- **제약** — 표준 라이브러리만 쓴다, 조용한 보정 없이 저장 전에 거부한다, 기존 설정 파일과 호환된다(`directives.categories` 가 없으면 지금과 같다).
- **버린 대안** — 새 상위 범주 허용(축을 사람이 골라야 하고 갈래 위반 자리가 생긴다 — 유저가 고르지 않음) · 플러그인 분류 파일에 직접 추가(업데이트 때 덮인다) · voice 가 전역 범주를 재정의(지금 요구에 없다, 전역에서 고치면 된다).
